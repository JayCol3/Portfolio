About

I'm a software developer who loves working through a hard problem until the data — or the code — finally makes sense. I'm a graduate of The Tech Academy's Software Developer Boot Camp, trained across the full stack: HTML, CSS, JavaScript, SQL, Python, and C#/.NET.
